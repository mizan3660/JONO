# Jono

Jono is a social networking Android app project.

Planned modules: Login/Register, Home Feed, Profiles, Search, Friends/Follow, Posts, Stories, Reels, Messenger, Groups, Pages, Notifications, Verification, Subscription, Reports, Privacy/Security and Admin Panel.

## Firebase
Create a Firebase project, add Android package `com.jono.app`, download `google-services.json`, and place it at `app/google-services.json`. Enable Authentication, Firestore and Storage.

## Build
Open in Android Studio or build through GitHub Actions/another Android CI service after uploading the project to GitHub.
